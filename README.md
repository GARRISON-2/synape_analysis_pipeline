# Synapse Analysis Pipeline
Python TKinter application for running [CruzMartinsLab's](https://github.com/CruzMartinLab) synapse analysis pipeline.


## Setup

After cloning the repository, the python environment can be set up using conda.

```bash
$ conda env create -f environment.yml
```

Before running the pipeline, ensure you have formatted an input/output directory with the following structure:

```
├── output_dir/      
│   ├── full_stack_img_dir/ 
│   │   └── L23_0001.tif
│   │   └── L23_0002.tif
│   │   └── ...
```
